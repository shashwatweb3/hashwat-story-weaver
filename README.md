# PERFORMANCE

This is an animation-heavy site, so performance is critical.

Requirements:

* lazy-load images
* use optimized image formats
* avoid huge uncompressed assets
* avoid unnecessary React re-renders
* use GPU-friendly transforms
* don't animate expensive layout properties unnecessarily
* respect `prefers-reduced-motion`
* avoid excessive simultaneous animations

Target a smooth experience.
